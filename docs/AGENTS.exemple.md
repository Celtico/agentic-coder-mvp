# Instruccions del projecte

Copia aquest fitxer a l'arrel del teu projecte amb el nom `AGENTS.md` i canvia'l al teu gust.
L'agent el llegeix a cada missatge i el segueix sempre; el que escriguis al xat mana per sobre.
Fes-lo curt: només se'n llegeixen els primers 4.000 caràcters (1.200 amb el model petit).

- Parla sempre en català.
- Aquest projecte és React amb Vite.
- Per iniciar-lo: npm start.
- Quan acabis un canvi, arrenca el projecte i comprova que la pàgina es veu bé.
- No facis commits de Git si no t'ho demano.
- No toquis la carpeta `public/`.
